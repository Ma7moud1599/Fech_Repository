# Fetch Repository — GitHub API Explorer

A JavaScript app that fetches and displays GitHub user repositories using the GitHub REST API. Enter a username and browse their public repos with details like language, stars, and description.

## Features

- Search any GitHub username
- Display all public repositories in a card grid
- Show: repo name, description, language, star count, fork count
- Click through to the repo on GitHub
- Loading state and error handling for invalid usernames

## Running

Open `index.html` in any browser — no API key required (uses public GitHub API).

## Tech Stack

Vanilla JavaScript, Fetch API, GitHub REST API v3, HTML5, CSS3
